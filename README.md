# Évaluation — Hibernate / JPA

Trois applications Java utilisant Hibernate et MySQL.

## Exercice 1 — Gestion de stock

![Produits dont le prix est supérieur à 100 DH](Exercice1-GestionDeStock/Screenshot%202026-10-17%20142846.png)

La console affiche les produits dont le prix est strictement supérieur à 100 DH, à l’aide de la requête nommée.

![Catégories enregistrées dans la base de données](Exercice1-GestionDeStock/Screenshot%202026-10-17%20142935.png)

Les catégories sont enregistrées dans MySQL avec leur identifiant, leur code et leur libellé.

![Lignes de commande et quantités](Exercice1-GestionDeStock/Screenshot%202026-10-17%20142949.png)

Chaque ligne associe une commande à un produit et indique la quantité commandée.

## Exercice 2 — Gestion de projets

![Tâches dont le prix est supérieur à 1 000 DH](Exercice2_Gestion_Projets/Screenshot%202026-10-17%20145039.png)

La console présente les tâches dont le prix est strictement supérieur à 1 000 DH, obtenues avec une requête nommée.

![Tâches enregistrées dans la base de données](Exercice2_Gestion_Projets/Screenshot%202026-10-17%20145131.png)

La table contient les tâches avec leurs dates planifiées, leur prix et l’identifiant du projet auquel elles appartiennent.

## Exercice 3 — Gestion de l’état civil

![Mariages en cours et mariages échoués d’un homme](Exercice3/Screenshot%202026-10-17%20150648.png)

Les mariages de SAFI SAID sont séparés en mariages en cours et mariages échoués, avec les dates et le nombre d’enfants.

![Tables des personnes et des mariages](Exercice3/Screenshot%202026-10-17%20150732.png)

La base de données contient 15 personnes, correspondant aux 10 femmes et 5 hommes du programme, ainsi que 11 mariages.
